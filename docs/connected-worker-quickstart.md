# Connect your machine

New accounts start with no workers. On your own Mac, Linux machine, or VPS with Bun 1.3+, Node.js 18+ with npm, and Git 2.42+, copy the three commands from **Settings → Workers**, which name your environment's exact version and Octomerge's npm registry: install the CLIs with `bun install --global --backend=copyfile @octomerge/otti-worker@<version> @octomerge/otti@<version> --registry https://npm.octomerge.dev`, sign in with `otti-worker auth` (the same sign-in as `otti auth login`; one is enough per machine) and approve the device in the browser with Full access, which a worker needs, then run `otti-worker start --label my-laptop`. Keep that process running, or [run it as a service](get-started/worker-service.mdx), and choose the worker in Octomerge's conversation menu. Configure your own model provider in Settings before sending a prompt.

See [Connect a worker](get-started/add-worker.mdx) for the requirements, Bun's `PATH`, Docker and retained-work details, and [Use otti](cli/otti.mdx) for command-line access.
