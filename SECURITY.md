# Security

Report security vulnerabilities in Octomerge privately, by email to [contact@octomerge.dev](mailto:contact@octomerge.dev). Please don't open a public issue for them.

Tell us what you found, how to reproduce it and what an attacker could do with it. We'll reply as soon as we can and keep you posted while we fix it.

This covers octomerge.dev and its subdomains, Octomerge's command-line tools (`otti`, `otti-worker`, `otti-browser` and `otti-macos-vm`), its container images and this manual. Octomerge's [security.txt](https://octomerge.dev/.well-known/security.txt) names the same address.
